Learning path 03

Algorithms

A study guide for recognizing a problem, choosing a technique, and understanding what the solution costs.

The examples will be added as they are implemented and tested. For now, this page defines the sequence and the questions each technique should answer.

The approach

Do not memorize the pattern before understanding the problem.

For each technique, start with the shape of the input and the operation that is too expensive. Then identify the invariant that lets the algorithm avoid repeating work.

  • What information must remain true after each step?
  • Which work can be reused instead of repeated?
  • What input or boundary case breaks the first idea?
  • How does the running time change as the input grows?

Study sequence

Techniques to work through.

01 · First principles Complexity and invariants Describe the cost and the condition that stays true
02 · Sequence patterns Two pointers and sliding window Turn repeated range work into a controlled scan
03 · Search Binary search and search spaces Use ordering to discard half of the remaining work
04 · Ordering Sorting and divide-and-conquer Break a problem apart, solve the pieces, and combine them
05 · Structure Tree and graph traversal Explore connected state without losing track of what was visited
06 · State Recursion, backtracking, and dynamic programming Make choices, remember useful results, and avoid duplicate work
